Download routing

Files downloaded from a matching site land in ~/Downloads/<subdir>/ instead of the default Downloads folder. Sortie watches those subdirs and runs stash add on each new file, so you get a one-gesture capture from Google Photos, Bandcamp, etc. Chrome only lets the extension reroute under your default Downloads folder — that's why every subdir starts with stash-.

How host patterns match
  • photos.google.com — matches that exact host and any subdomain of it.
  • *.bandcamp.com — same as .bandcamp.com; matches any subdomain (artist.bandcamp.com, bandcamp.com).
  • The extension first checks the download's referrer; if missing, it falls back to the active tab's URL.
